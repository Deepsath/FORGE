# ⚒ FORGE v1.0

> Build Yourself. Every Day.

FORGE is a command-line productivity application built using Python. It helps users create, manage, and complete personal goals while tracking their overall progress.

---

## 🚀 Features

- ➕ Create new goals
- 🎯 View active goals
- ✅ Complete goals
- ✏ Rename goals
- 🗑 Delete goals
- 🏆 View completed goals
- 📊 Dashboard with completion rate
- 💾 Automatic data saving
- 🔄 Persistent storage using text files

---

## 🛠 Built With

- Python 3
- File Handling
- Functions
- Lists
- Loops
- Exception Handling
